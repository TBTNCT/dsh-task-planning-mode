### 偏离计划之处

1. **落点变了（按横幅）**：任务书正文写 `presets/task-planning/plugins/token-estimator/index.js` + 相对行 `name: './plugins/…'`；
   实际落在 `presets/task-planning-bundle/plugins/token-estimator/index.js` + 行 `name: dsh-task-planning-preset/plugins/token-estimator/index.js`。
   → 机制原因**已实测定位**（不是猜测）：loader 相对行名按 `new URL(name, ctx.baseUrl)` 解析，而
   `ctx.baseUrl` 是 **profile 配置目录**（`dsh-app-boot/lib/index.js:1529`），相对路径会指到 profile 下。
   `presets/task-planning/agent.cordis.yml` **保持 0.1.x 留档原样未改**（与任务 02 一致）。
2. **"复制到用户层 `.agent-presets\task-planning\`"未做**：0.2.x 不扫描该目录（死数据），且铁律 1 禁写 `profiles\`；
   本机运行期副本就是 `link:<REPO>\presets\task-planning-bundle`（就地读仓库文件）。
3. **E1/E2/E3 用"机器等价实验"执行**（Node 直调 + 源码只读），**未重启桌面端**：
   重启会打断当前会话，且任务书本就要求"新开会话"的动作由人工执行。
   → 机器实验覆盖了"行名怎么解析 / 模块能不能 import"；**"设置页卡片是否无加载失败"留给人工**（§六）。
4. **加了 `"type": "module"`**：任务书没提，但 bundle 原本没有它，`.js` 会被当 CJS 而 `export` 报错；
   依据是本机两个可用本地 bundle 的既有惯例。
5. **未加挂任何新工具行**：本插件自己注册工具，不引入 `@deepseek-ai/*` 新行；范围围栏（不挂 schedule/goal/plan-mode/子代理/工作流）保持不动。
6. **`usage_report` 的 `sessionId` 参数只用于标注**：本版本不去读其它会话的日志（跨会话读取没有已核实的公开 API）；
   已在工具返回值与注释里写明，避免"假装能查别人会话"。

## 三、关键数据

- **插件规模**：`plugins/token-estimator/index.js` 单文件、**1 条导入**（`node:process`）、零第三方依赖；注册 **2** 个工具。
- **契约校验**：`assertSupportedJsonSchema` 对 `parameters` 与 `output.schema` **各 2 次全 PASS**；
  返回值对 `output.schema` 的 `validateJsonSchemaValue` **4 次全 `output conforms`**（0 违规）。
- **bundle 校验**：`validate-bundle.cjs` **0 FAIL**（改校验器后；改前唯一 FAIL 是校验器把文件路径行拼成 `…/index.js/lib/index.js` 的假阳性）。
- **E2 报错原文**：`ERR_MODULE_NOT_FOUND: Cannot find package 'zod' imported from <REPO>\presets\task-planning-bundle\plugins\probe\e2-bare-import.mjs`。
- **量级标定**：`estimate_tokens({stage:"本项目（8 个主任务的插件开发）", scale:{tasks:8,files:40,docChars:60000,existingCodeLines:5000}})` → **低 4,636,800 / 高 14,490,000 / 合计 14,345,100**，两个阈值均**未触发**。
  对标 `docs/工作流程/00-总览与使用说明.md` §八「任务 01–08 = 4.7M–14.5M」→ **同量级**。
- **运行时实测（人工，2026-10-12）**：模式内 `usage_report` 返回**已用 7.6K token**（运行时计量口径，主口径 `sessionProjections.tokenUsage`）；
  同一次调用里静态侧按**默认规模**（1 子任务 / 3 文件 / 4000 字）给区间 **0.57M–1.78M**、保守合计 **1.76M**。
  → **两者口径不同**（"当前会话累计" vs "整个阶段预估"），不能单点相减；见 §四第 1 条。
- **公式常量**（改动即改算法，须同步注释）：`BASE_TOKENS_PER_TASK=700_000`、`每行代码 8`、`每文件读 600`、`每字 1.2`、`每文件产出 1500`、`低 ×0.8`、`高 ×2.5`、`重试系数 1.5`、`默认迭代 3`。
