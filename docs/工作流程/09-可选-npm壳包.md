## 一、任务目标

让安装从"下载仓库 + 跑脚本"变成"`npm i` 一下"。**但必须先接受一个前提**：

> DSH 的 `package.json` → `dsh` 字段**没有 preset 声明能力**。所以 npm 包**不可能**做到"装完 DSH 就自动认识这个模式"。npm 包在这里只能是**搬运工**：
> - 要么包含 preset 目录 + 一个安装器（把目录复制到 `.agent-presets`），
> - 要么配合 profile 的 `roots` 配置（仍需改 patch + 重启，且要重述 `default`）。

**值不值得做？** 只有当使用者群体确实习惯 npm、且你愿意长期维护发布流程时才值得。否则 README 里的"复制目录"已经够用——这也是为什么本任务被标为可选。

## 五、常见问题

- **`postinstall` 不执行**：使用者可能带 `--ignore-scripts` 安装；所以文档必须同时给"手动复制"步骤。
- **scoped 包发布被拒（402）**：加 `publishConfig.access: public` 或命令带 `--access public`。
- **以为装上就完事**：回到前提——manifest 没有 preset 能力，npm 包只是搬运工。
