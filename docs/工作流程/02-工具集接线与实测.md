## 一、任务目标

把「任务规划」模式需要的**标准档工具**全部接上，并且**逐个实测**，产出一张"工具 → 可用性 → 证据"的表。

为什么工具要一个个挂？因为 **preset 不会继承标准模式的工具**：标准模式挂了几十行，本模式只拿到自己声明的那些。缺一行，模式就少一个能力。

**标准档（你已确认的权限档位）**：读写文件 + 文本检索 + 联网 + 提问 + 任务板 + 执行命令 + 上下文压缩。**不含**子代理 / Agent Teams / 工作流 / 计划模式 / 目标 / 自我修改（`tool-cordis`）。

## 二、开场准备

1. 工作区选 `<REPO>`，新建对话，把第三节提示词整段复制发送。
2. 若 AI 读不到工作区文件，拖入 `docs\调研\01-preset机制.md`、上一任务的 `agent.cordis.yml`。

## 五、常见问题

- **某个工具行导致挂载失败**：多半是"服务泄漏进 root realm"——该能力需要 `isolate` group。先读该包 README 的"何时使用"章节，别硬试。
- **`present` 或 `tool-jobs` 行加了但工具没出现**：检查是否被 `disabled` 条件挡住（`!!js` 表达式在本机是否成立），或宿主层没提供该服务。
- **联网失败**：先确认 `tool-web` 行在，再确认宿主的搜索提供方可用（宿主平面的事，preset 管不了）；把结论写进表里。
