## 一、任务目标

让 **「任务规划」这个模式真的出现在 DSH 的模式选择器里**，并且切进去之后能用最基础的三件事：向你提问、读写文件、检索文件。

本任务**只做骨架**：不做完整工具集（那是任务 02）、不做 token 估算器（任务 03）、不写正式系统提示词（任务 04）。系统提示词位置先放一句占位文本。

> 关键认知：DSH 的"模式"就是 **Agent Preset**，一个目录 + 两个文本文件，**不需要编译**。用户自建模式放在 `%USERPROFILE%\.dsh\.agent-presets\<模式id>\`。

## 二、开场准备

1. 用 VS Code 打开 `<REPO>` 文件夹。
2. 本任务为**新建对话**，工作区选上面这个目录，把第三节【提示词】整段复制发送。
3. 若 AI 读不到工作区文件，把 `docs\调研\01-preset机制.md` 和 `docs\优化提示词\01-通用规范.md` 拖进对话。

## 五、常见问题

- **选择器里没有「任务规划」**：先 `新开会话`；再确认目录名是 `task-planning`（全小写、连字符）；必要时重启 DSH 桌面端。
- **显示 broken**：看「设置 → Agent presets」里的报错，通常是 YAML 顶层不是数组、某行缺 `name`、或包名解析不到。
- **模式里没有写文件工具**：`tool-fs` 行没挂上，或缺 `id`。对照官方 `standard/agent.cordis.yml`。
- **写入 D: 报权限错误**：确认路径就是 `<REPO>`（已实测可写），不要写到 `C:\Program Files`。
