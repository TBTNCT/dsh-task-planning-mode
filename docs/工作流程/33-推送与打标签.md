## 五、常见问题

- **push 被拒（non-fast-forward）**：这是预期的，因为历史被重写了。确认你用的是 `--force-with-lease`。
- **`--force-with-lease` 被拒（stale info）**：说明远端在你上次 fetch 之后被动过。先 `git fetch origin` 看清差异，再决定；**不要**直接改用 `--force`。
- **tag 指向错了提交**：删掉重打（`git tag -d` + 重新 `git tag -a` + `git push origin :refs/tags/<名字>` 再推）。错的 tag 比没有 tag 更麻烦。
- **远端复扫仍然有命中**：说明重写没覆盖干净，**停下**，回到任务 31 排查。**不许**因为"本地是干净的"就当它过了。
- **想顺便把 Release 也发出来**：本任务不含发 Release；若要发，先确认发布说明的内容（可以参照 `docs/实施记录/12-Release草稿-v1.2.0.md` 的格式）另开任务。
