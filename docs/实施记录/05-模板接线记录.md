## 2. skill 挂载方式：为什么**不能**照抄官方创造模式的写法

### 2.1 任务书建议的写法（官方创造模式用过）

任务书 §三 第 3 项给的挂法是官方 `presets/cordis/agent.cordis.yml` 的原文：

```yaml
- id: skill-filesystem
  name: '@deepseek-ai/dsh-skill-filesystem'
  config:
    customSkillDirs:
      - !!js "process.getBuiltinModule('node:url').fileURLToPath(new URL('skills/', baseUrl))"
```

（只读复核：`<DSH_INSTALL>\node_modules\@deepseek-ai\dsh-agent-presets\presets\cordis\agent.cordis.yml:256-260`，
该文件自己的注释写着「`baseUrl` is the preset's own directory, so the root resolves wherever the preset is installed」。）

### 2.2 机制：那句话只对「被 include 的子树」成立，对**补丁层**不成立

```text
<DSH_INSTALL>\node_modules\@deepseek-ai\dsh-app-boot\lib\index.js:140（Include 构造，子树才有自己的 baseUrl）
  this.ctx.baseUrl = new URL(".", pathToFileURL(this.filename)).href;

…同文件:1529（boot 给 profile 根设的 baseUrl）
  ctx.baseUrl = pathToFileURL(dirname(absoluteConfigPath)).href + "/";

…同文件:845-870（loadProfileDirectory：bundle 的 patch 被**读出来当补丁列表**，再 compose 到 profile 根）
  const declared = JSON.parse(readFileSync(join(packageDir, "package.json"), "utf8")).dsh?.bundle?.patch;
  return { packageName, packageDir, patchPath, patches: loadOverlayPatches(binName, patchPath) };
```

本 bundle 的 `cordis.patch.yml` 是**补丁层**，不是被 include 的子树 —— 它的行拿到的 `baseUrl`
仍是 **profile 配置目录**。这与任务 04 在 `persona.config.prefix` 上踩的是同一个坑
（`docs/实施记录/04-提示词接线实测.md` §2 有完整源码证据与 ENOENT 原文）。

### 2.3 实际采用的写法

```yaml
          - id: skill-filesystem
            name: '@deepseek-ai/dsh-skill-filesystem'
            config:
              customSkillDirs:
                - !!js "process.getBuiltinModule('node:path').join(process.getBuiltinModule('node:path').dirname(process.getBuiltinModule('node:module').createRequire(new URL('noop.js', baseUrl)).resolve('dsh-task-planning-preset/package.json')), 'skills')"
```

即：与同文件的 `persona` 行、`token-estimator` 行走**同一条解析基准** ——
profile 的 `node_modules` 里有本 bundle 的 link（`dsh-task-planning-preset`
→ `..\..\..\..\plugins\dsh-task-planning-mode\presets\task-planning-bundle`，安装时建立），
所以按包名解析到 `package.json`，再取同级的 `skills/`。**不含任何绝对路径**，可开源分发（任务 08 要求）。

### 2.4 实测（运行方自带的解析器 + 求值器，原文见 §4）

| 写法 | 真实 `baseUrl` 下求值结果 | 该目录存在 |
|---|---|---|
| 官方写法 `new URL('skills/', baseUrl)` | `%USERPROFILE%\.dsh\profiles\desktop\skills\` | **false**（读不到本包的 skills/） |
| **本任务写法**（按包名解析） | `<REPO>\presets\task-planning-bundle\skills` | **true** |

## 3. 代价：模板放 skill 而不是塞进系统提示词

### 3.1 两个口径分开算

| 口径 | 改前（哨兵 v3） | 改后（哨兵 v4） | 差 |
|---|---|---|---|
| `PROMPT.md` 汉字数 | 7721 | **7899** | **+178** |
| `PROMPT.md` 总字符 | 13059 | **13396** | +337 |
| **每请求 token（粗估）** | 约 12.9k | **约 13.2k** | **约 +0.31k** |

口径：汉字 × 1.5 + 非汉字字符 ÷ 4 的**粗估**（与任务 04 §3 同口径，未用 `estimate_tokens` ——
该工具算的是「阶段/任务规模」，不适用于「单份文件字数 → 请求开销」这类换算）。

### 3.2 如果反过来把骨架塞进系统提示词

`SKILL.md` 本身 **4830 汉字 / 9890 字符**，同口径粗估 **约 8.5k token**。
`skill-filesystem` 的 `get()` 返回的正文字符数为 **9729**（§4 §3 原始输出，不含 frontmatter）。

| 方案 | 每请求成本 | 只在产出文档时付出的成本 |
|---|---|---|
| 骨架写进系统提示词 | 约 13.2k + 8.5k = **约 21.7k**（**每一次请求都付**，含纯提问轮） | — |
| **骨架放 skill（本任务采用）** | **约 13.2k**（只多了那 178 个字的硬要求） | 约 8.5k，**只在模式真正产出文档的那几轮**由 `skill` 工具按需载入 |

结论：**每个请求省下约 8.5k token**；代价是模式多一次 `skill` 工具调用、且骨架内容不在
"随时可见"的注意力范围内 —— 所以 §六第 7 条与 §十二第 2 条**双写**了"必须先加载"这条硬要求，
并在加载不到时给了明确的回退口径（写明「skill 不可用，已自行生成」），避免它悄悄退回即兴发挥。

### 3.3 系统提示词因此增加了多少要求

| 位置 | 改动 | 性质 |
|---|---|---|
| §六第 7 条 | 条件句「若本模式自带…则…」→ **硬要求**「产出任何规划文档之前，必须先加载」+ 5 类骨架清单 + 【必须】不得删减 / 【可选】须说明理由 + 加载不到时的回退与自述口径 | **升级为硬要求**（任务 04 已埋的前向接口，本次收口） |
| §十二 自检清单 | **新增第 2 条**（原 2–10 顺延为 3–11）：产出文档前是否先加载 skill / 【必须】是否被删减 / 省略【可选】是否说明原因 | **新增 1 条** |

其余 10 条自检项与 11 条硬约束**一字未改**（任务 04 报告的提醒：不要把提问相关措辞改回去 —— 本次未动）。

### 7.0 为什么要重启（先看这条，否则会误判"写了没用"）

`skill-filesystem` 的 `customSkillDirs` 是 `!!js`，**只在 preset 挂载激活时求值一次**；
而 preset 的重组代际只看**补丁文件** `cordis.patch.yml` 的 mtime+size。
本次已同时改了补丁文件与 `PROMPT.md`，所以**重启桌面端 + 新开会话**是必需的，
不是"试试看"——这一步本身就是本任务要记录的生效口径。

### 7.1 前置（3 步）

1. **重启 DSH 桌面端**。
2. 打开 **设置 → Agent presets**，确认「任务规划」卡片**没有「加载失败」红标**
   （有红标就把红标原文抄下来 —— 那属于本任务的 ❌ 项）。
3. **新开一个会话**：
   - **工作区**选 `<REPO>\demo\_自测`（**不要**选仓库根目录）；
   - **模式**选「**任务规划**」。

### 7.2 先验生效口径（1 句，10 秒）
