## 三、重写方式

```bash
# 备份（不可逆操作前的唯一退路）
git bundle create <临时目录>/before-rewrite.bundle --all

# 重写：41e773e 之后的所有提交
git filter-branch -f \
  --tree-filter  'node tools/privacy-sanitize.mjs --root . --all --quiet' \
  --msg-filter   'node <msg-filter.mjs>' \
  --env-filter   'export GIT_AUTHOR_NAME="dsh-task-planning-mode contributors"; ...' \
  41e773e..HEAD
```

- **文件内容**：每个提交的整棵树都过一遍 `privacy-sanitize.mjs`，占位符由规则文件统一决定：
  家目录 → `%USERPROFILE%`、用户名 → `<user>`、邮箱 → `<EMAIL_REDACTED>`、仓库根 → `<REPO>`、
  DSH 目录 → `<DSH_DIR>` / `<PLUGINS_DIR>`、桌面 → `<DESKTOP>`。
- **提交信息**：同一条规则集过滤，清掉提交正文里的桌面路径（占位为 `<DESKTOP>`）。
- **作者 / 提交者**：统一改为 `dsh-task-planning-mode contributors <noreply@example.com>`，
  **提交信息文本与提交时间保持不变**。
- **顺序**：先在备份克隆里试跑一遍并复扫通过，再对正式仓库执行。
