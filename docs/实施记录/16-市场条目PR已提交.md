## 三、本次实际操作与踩坑（供下次复用）

### 3.1 环境事实（实测，与任务文档假设不同的地方）

| 项 | 文档假设 | 本机实际 |
|---|---|---|
| 桌面目录 | `$env:USERPROFILE\Desktop` | ❌ 不存在；真实桌面不在用户目录下（本机被重定向到非系统盘，路径见注册表 `User Shell Folders` 的 `Desktop` 值） |
| GitHub 账号 | `<你的用户名>` | **`TBTNCT`**（`gh api user --jq .login`） |

**踩坑**：文档里的 `<REPO>` / `<你的用户名>` 是占位符，直接粘贴会报
「路径中具有非法字符」（`<` `>` 在 Windows 路径非法）或 PowerShell 解析错误
（「`<`运算符是为将来使用而保留的」）。**占位符必须整体替换。**

### 3.2 实际执行的命令序列

```powershell
# 0) fork（已在 11:12:07 由 gh 建立）
gh repo fork awesome-dsh-plugin/awesome-dsh-plugin --clone=false

# 1) 克隆到你自己的目录（本机桌面不在用户目录下，先按注册表的 Desktop 值定位）
Set-Location '<你的工作目录>'
gh repo clone TBTNCT/awesome-dsh-plugin
Set-Location '.\awesome-dsh-plugin'

# 2) 建分支
git switch -c add/tbtnct-dsh-task-planning-mode

# 3) 写条目（PS 5.1 必须用 WriteAllText，避免 BOM）
$path = 'data\plugins\TBTNCT__dsh-task-planning-mode--presets-task-planning-bundle.yml'
$yaml = @'
url: https://github.com/TBTNCT/dsh-task-planning-mode/tree/main/presets/task-planning-bundle
name: TBTNCT/dsh-task-planning-mode#task-planning-bundle
category: workflow
description:
  en: 'Adds a "Task Planning" agent preset that asks requirements in versioned rounds, then writes step-by-step plans and prompts without implementing them itself.'
  zh: '为 DSH 增加「任务规划」模式：按版本迭代逐轮提问把需求问清楚，再产出可逐条执行的规划与提示词，自身不实现代码。'
'@
[System.IO.File]::WriteAllText((Join-Path (Get-Location) $path), $yaml, (New-Object System.Text.UTF8Encoding($false)))

# 4) 提交推送
git add $path
git commit -m "Add TBTNCT/dsh-task-planning-mode"
git push -u origin add/tbtnct-dsh-task-planning-mode

# 5) 开 PR
gh pr create --repo awesome-dsh-plugin/awesome-dsh-plugin `
  --title "Add TBTNCT/dsh-task-planning-mode" `
  --body "Adds a Task Planning agent preset. Published on npm as dsh-task-planning-preset. ..." `
  --head TBTNCT:add/tbtnct-dsh-task-planning-mode
```

### 3.3 一个容易误判的信号

`git commit` 时出现警告 `LF will be replaced by CRLF the next time Git touches it` ——
**不是错误**，是 Windows 换行符转换提示。CI 通过说明无影响（Git 会按 `.gitattributes` 存储）。
