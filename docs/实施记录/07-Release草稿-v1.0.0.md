# v1.0.0 · 「任务规划」模式

给 **DeepSeek Harness（DSH）** 加一个模式：**先把你要的效果问清楚，再拆成可以一段一段执行的规划与提示词。**
它自己不动手实现——实现留给标准模式。

面向「完全不了解目标行业、但明确知道自己想要什么效果」的人。

---

## 安装（DSH 0.2.x，实测可用）

1. DSH 桌面端 → 左侧栏 **插件** → **添加插件**
2. 在包名框里粘贴本仓库 `presets/task-planning-bundle` 的**绝对路径**
3. 点 **安装** → **立即启用**
4. **完全重启桌面端**
5. 新开会话 → 模式选择器里选「**任务规划**」

> ⚠️ 装完**必须完全重启**桌面端，模式才会出现（官方对话框不会提示这一点）。
> 若报 `ERR_PNPM_UNEXPECTED_STORE`，修法见 `presets/task-planning-bundle/README.md` 第二节。

完整说明（含 0.1.x 旧机制路线与回滚方法）见 **README.zh.md** / **README.en.md**。

## 本版内容

- **「任务规划」模式本体**（声明式 preset bundle）：13 小节系统提示词 + **12 条硬性约束**（首尾双写）+ 4 组作业纪律；
  标准档工具集内联在 `config.plugins` 里。
- **token 估算器本地工具插件**：`estimate_tokens`（可解释的静态区间 + 6000 万 / 2 亿阈值判定）
  与 `usage_report`（优先读运行时计量，读不到降级）。单文件、纯 ESM、**零第三方依赖**。
- **规划文档模板 skill**：5 类规划文档的【必须】/【可选】章节清单 + 可直接复制的骨架。
- **Demo**：`demo/shelter-idle/`（末日避难所挂机）——用本模式真跑出来的样例。
- **开源前隐私门禁**：`tools/privacy-*`，工作区 + **全部提交历史**双向扫描；规则分两层（通用规则入库、本机字面量不入库）。
- **安装/卸载脚本**：`install.ps1` / `uninstall.ps1`，脚本内不含任何个人绝对路径。

### 新增规范

- `docs/优化提示词/02-开源前隐私规范.md`：**最终程序只要有开源需求，开源前必须保证个人信息零泄露**；
  个人签名允许但不强制。该规范同时是模式硬约束 ⑫。

## 已知限制

- preset **据机制推导**不能携带浏览器 UI（**推导，未做运行时验证**）。
- 用户自建 preset 在模式列表里的精确排序语义为**推导**，未枚举验证。
- 装完通常要**重启桌面端**模式才出现（是否启用 HMR 未实测）。
- 升级需手动：先卸载再装新版。
- `PROMPT.md` 体积偏大（14691 字符 / 8664 汉字），每个请求都要加载。

## 安全提示

**preset 的信任等级等价于 shell 访问。** 装一个 preset = 允许它在你机器上组装任意工具组合。**只装可信来源。**
本 bundle 自带 1 个本地 JS 文件（token 估算器），装前建议自己读一遍。
