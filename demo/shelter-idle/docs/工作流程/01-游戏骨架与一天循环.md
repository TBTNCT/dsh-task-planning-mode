# 任务 01：游戏骨架与一天循环

> **阶段**：v0.1 能跑起来
> **前置任务**：无（本项目第一个任务）
> **建议同时提供**：`docs/优化提示词/01-通用规范.md`（铁律与数值基线 §4.1）、`docs/工作流程/00-总览与使用说明.md`（工作方式）
> **本任务产出**：能开局的终端程序 —— `node src/game.js` 打开后看到状态面板与编号菜单，点「1」推进一天并结算资源
> **对话方式**：新建对话

## 一、任务目标

把《末日避难所》的**骨架**搭起来：一个纯文字终端程序，能在本机 `node src/game.js` 直接跑。

- 开局显示状态面板（天数 / 人口 / 食物 / 电力 / 四个房间等级）与编号菜单；
- 点「1」推进一天，按 `01-通用规范.md` §4.1 的**固定结算顺序**算产出与消耗，并把当天发生了什么写成中文日志；
- 建立 `tests/check.js` 自检脚本与 `README.md` 使用说明；
- 四个房间本任务**只显示等级（全为 0）**，升级功能留到任务 02。

这一步不做存档、不做离线收益、不做事件、不做结局判定——那些是任务 03 / 04 的事。

## 五、常见问题

- **终端里中文是乱码**：先在 PowerShell 里执行 `chcp 65001` 再跑；把原始输出贴回对话让 AI 判断，
  不要自己改代码编码。**不要**在源码里加 BOM。
- **报错 `Cannot use import statement outside a module`**：AI 写了 ESM 语法。这是铁律 6 违规，
  让它改成 `require` / `module.exports`，不要新建 `package.json` 绕过。
- **自检脚本报「缺电日产出减半」失败**：先确认 `advanceOneDay` 里耗电那一步是否**先把 power 扣到 0 再判断缺电**，
  顺序错了就会算错；把失败断言的原始输出贴回对话。
- **点「1」之后数字没变**：多半是 `advanceOneDay` 改了对象副本而不是原对象（引用没传对），
  让 AI 打印一次 `state` 前后对比来定位。
- **AI 顺手把房间升级也做了**：叫停，要求撤回。多做的部分会让任务 02 的验收证据失效。
