# 末日避难所 · 使用说明

纯文字终端小游戏，Node.js 编写，**零第三方依赖**，只在 Windows 本机终端里跑。
本文件对应当前进度：**任务 01（游戏骨架与一天循环）**。

---

## 一、怎么跑起来

1. 打开 Windows PowerShell。
2. 先切到 UTF-8 代码页，避免中文显示成乱码：

   ```powershell
   chcp 65001
   ```

3. 进入本工作区目录（就是本文件所在的目录）：

   ```powershell
   cd <REPO>\demo\shelter-idle
   ```

4. 启动游戏：

   ```powershell
   node src/game.js
   ```

启动后你会看到状态面板和编号菜单：

```
========================================
 末日避难所 · 第 1 天
========================================
 人口 3/3    食物 40    电力 10
 宿舍 L0 水培农场 L0 发电机 L0 医疗室 L0
----------------------------------------
 1. 推进一天
 2. 查看最近 10 条日志
 3. 退出
========================================
 请输入编号：
```

（`L0` 表示该房间等级为 0，也就是还没建造。房间升级是任务 02 的内容。）

---

## 二、菜单各项是什么意思

| 编号 | 名称 | 点了会发生什么 |
|---|---|---|
| 1 | 推进一天 | 天数 +1，按固定顺序结算发电、耗电、产食、吃饭、人口增长，然后重画状态面板，并在面板下面打印这一天的中文日志 |
| 2 | 查看最近 10 条日志 | 只打印最近 10 条日志（不再重画面板） |
| 3 | 退出 | 打印「游戏结束，再见。」后正常退出，终端回到提示符 |

**输入别的任何东西都不会出事**：空回车、字母（例如 `abc`）、`0`、`9` 等，程序都会提示
`请输入 1-3 之间的编号`，然后重新显示菜单。它不会崩溃，也不会退出。

### 怎么退出

- 按菜单提示输入 `3` 再回车，这是推荐的退出方式；
- 也可以直接按 `Ctrl+C`（强制结束，不会打印告别语）；
- 输入流结束（例如按 `Ctrl+Z` 再回车）时也会打印告别语并正常退出。

## 三、每天是怎么结算的（数字规则）

数值基线来自 `docs/优化提示词/01-通用规范.md` §4.1，**顺序固定，不许调换**：

1. 天数 +1；
2. **发电**：电力 += 发电机等级 × 4；
3. **耗电**：需求 = 水培农场等级 × 2 + 医疗室等级 × 1，先扣电；扣成负数就把电力按 0 算，
   本日标记「缺电」，第 4 步的农场产出减半（向下取整）；
4. **产食**：食物 += 水培农场等级 × 7（缺电日减半取整）；
5. **吃饭**：食物 -= 人口 × 1；不够就饿死人，饿死人数最多留 1 人（单日不会全灭），食物清零；
   医疗室每级有 15% 概率救回 1 人，每天最多救回 1 人；
6. **人口增长**：每 3 天一次，且食物 ≥ 10、人口未到上限时，人口 +1；
7. **事件判定**：本任务留空占位（任务 04 实现）；
8. **结局判定**：本任务留空占位（任务 04 实现）。

**人口上限** = 3 + 宿舍等级 × 3。

开局值是：第 1 天、人口 3、食物 40、电力 10、四个房间全 0 级。
所以第一天点「1」之后：天数变 2，食物 40 → 37（3 人各吃 1），电力仍是 10（没有房间耗电）。

## 四、自检脚本

```powershell
node tests/check.js
```

它会依次跑 6 项检查并打印每项结果，最后一行是汇总：

```
CHECK SUMMARY 通过 6 / 失败 0
```

有失败时会打印失败原因，并且退出码为 1。

## 五、文件结构

| 文件 | 职责 |
|---|---|
| `src/state.js` | 定义游戏状态的结构，提供 `createInitialState()` 造开局状态 |
| `src/rules.js` | 只放规则计算：`advanceOneDay(state)` 按 §4.1 的 8 步结算并返回本日日志数组；另有 `popCap()` 等 |
| `src/ui.js` | 只放终端显示：`renderStatus()`、`renderMenu()`、`renderLog()`，都返回字符串，由入口统一打印 |
| `src/game.js` | 入口：用内置 `readline` 做编号菜单循环 |
| `tests/check.js` | 自检脚本，用内置 `assert`，共 6 项断言 |
| `README.md` | 本文件 |

依赖方向是单向的：`game.js` → `ui.js` → `rules.js` → `state.js`。

## 六、常见问题

**中文显示成乱码？**
先在 PowerShell 里执行 `chcp 65001`，再跑 `node src/game.js`。不要自己去改源码的编码。

**提示 `Cannot use import statement outside a module`？**
说明代码里混进了 ESM 写法。本项目**没有** `package.json`，`.js` 一律按 CommonJS 解析，
只能用 `require` / `module.exports`，也不要新建 `package.json` 来绕过。

**能装依赖吗？**
不能。本项目零依赖，只用 Node 内置的 `fs` / `path` / `readline`，不需要也不允许 `npm install`。

**现在能存档吗？能挂机吗？**
还不能。存档与离线收益是任务 03，事件与 60 天结局是任务 04，房间升级是任务 02。
本任务只做「能开局 + 能推进一天 + 数字对」。

**数字觉得太简单或太难，能改吗？**
本任务不许改。只有任务 04 完成后的端到端自检里，按 `01-通用规范.md` §4.2 的调参规则才允许改，
并且必须同步改那份文档。
